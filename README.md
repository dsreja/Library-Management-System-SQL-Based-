# Library Management System (SQL Project)

This project is a simple SQL-based Library Management System. It allows management of books, members, and borrowing activities using SQL queries.

## 📂 Files Included
- `schema.sql`: Contains table creation scripts.
- `insert_data.sql`: Adds sample records to the database.
- `queries.sql`: Useful queries for managing and reporting.
- `ERD.png`: ER diagram of the database.

## 📋 Features
- Add and manage books
- Register library members
- Track which books are borrowed and returned
- Generate reports

## 💾 Tech Stack
- MySQL / PostgreSQL
- SQL

## 📊 ER Diagram
![ERD](ERD.png)

## 🚀 How to Run
1. Create a database in your SQL environment.
2. Run `schema.sql` to create tables.
3. Run `insert_data.sql` to populate sample data.
4. Use `queries.sql` to interact with the data.
